OFFLINE-FIRST SECURITY

Designed to help spot what you might miss.

◎

Office risk inventory

Inspect supported Office Open XML files for selected metadata, hidden content, external links, notes, embedded parts and possible sensitive-value indicators.

◇

Guarded metadata cleaning

Reject files containing detected non-removable risks; preserve the originals and independently verify allowed metadata-only copies.

▤

Privacy-conscious reports

Summarize findings with counts and opaque package references instead of reproducing matched personal information.

This beta is a heuristic review tool, not a complete content redactor. It does not comprehensively sanitize VBA source, images, classified documents or arbitrary PII. Human review remains mandatory.

XFCE INSTALLATION

Set up in a few steps.

01

Download the Debian package

Choose the beta .deb above and verify its SHA-256 checksum before installing.

02

Install with your package manager

sudo apt install ./%%DEB_FILE%%
03

Launch from the Office menu

Find Office Sanitizer under XFCE Applications → Office, or run office-sanitizer-gui.

Optional update checks use the network. Document scanning does not. Fully unattended updates and publisher-signed releases are not available yet.
